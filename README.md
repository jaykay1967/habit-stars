# Habit Stars

- **Android:** download [HabitStars.apk](https://github.com/jaykay1967/habit-stars/raw/main/HabitStars.apk). Once installed it updates itself from `version.json`.
- **Galaxy Watch:** [HabitStarsWatch.apk](https://github.com/jaykay1967/habit-stars/raw/main/HabitStarsWatch.apk) — install onto the watch (see instructions), works with the phone app.
- **iPhone:** open **https://jaykay1967.github.io/habit-stars/** in Safari → Share → **Add to Home Screen**. It updates itself whenever it opens.
